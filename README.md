## 🧪 Automation Testing

The project includes Selenium WebDriver automation scripts for validating functional scenarios of the TutorialsNinja web application.

The automation suite is continuously being enhanced with additional test scenarios and test scripts as testing progresses.

The automation framework uses:

* Selenium WebDriver
* Java
* TestNG
* Maven

---

## 📋 Test Case Documentation

A complete Excel file containing the manual test cases is included in this repository:

**TutorialsNinja Web Application - Test Cases (Complete and Final) (1).xlsx**

The test case documentation is maintained and updated as additional scenarios are identified and tested.

---

## ⚙️ Framework & Project Configuration

This project follows a Maven-based Selenium automation framework.

### Maven

Maven is used to manage project dependencies and build configuration.

The project dependencies are maintained in:

```text
pom.xml
```

### TestNG

TestNG is used for:

* Test execution
* Test organization
* Test annotations
* Test suites
* Test reporting
